页面没有启动

你现在看到的只是 HTML 骨架，三维模型没有加载。常见原因与解决办法：

  • 双击了源码目录的 index.html：浏览器不能直接运行 src/main.ts。
    请改为双击 dist/index.html（项目已按单文件方式构建，可直接打开）， 或在本目录执行 npm run dev 后访问提示的网址。
  • dist/index.html 打不开三维：请在本目录执行 npm run build 重新生成单文件版本，或执行 npx vite preview 用本地服务器打开。

若浏览器控制台提示 CORS / MIME，属于 file:// 的固有限制，用上面的任一方式即可解决。
