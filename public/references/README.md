## 专利要点（EP3932609B1）

- Claim 1：parallel-offsetting unit 至少三面镜，其中**一面可转**，
  **entry reflection 与 exit reflection 都发生在可转镜上**；
- Claim 3：固定镜数量为偶数；Claim 4：光束被反射**四次**；
- Claim 5：所有镜面法线共面；
- [0015]/[0030]/[0032]：一面可转 + 两面固定（26/28/30），四次反射，首末都在 26；
- [0016]/[0031]：每转角的位移量与镜间距有关，只有定性表述、**没有公式**；
- [0039]：平行移束的作用是让光束**相对光轴 oA 平行偏移**，偏心量 d 决定出射倾角 α。

> 专利**没有**描述可动镜带开孔/开槽/双面入射，也没有输出光束"平行于输入光束"的明文表述；
> 本页模型的处理方式与这些空白都已在界面与 README 中标注为"教学等效"。
