## 0. 两条技术路线怎么对照

页面顶部有**技术路线切换器**，两份实现共用同一套界面与读数口径，但**光路拓扑彼此独立**：

```
SCANLAB precSYS                                     Novanta / ARGES（本模型）
─────────────────────────────────────────────       ─────────────────────────────────────────────
激光入口 → 光束调理                                  激光入口 → 光束强度衰减单元 (I)
   │                                                    │
α 平行移束模块（三镜四反射，反射式）                    wobble unit (II)：两块**透射式平行平板**
β 平行移束模块（三镜四反射，反射式）                    │   板 A 绕 X 轴倾斜 → 位移沿 Y
   │                                                    │   板 B 绕 Y 轴倾斜 → 位移沿 X
Z 动态调焦等效模块（反射式功能等效）                    │   （两转轴正交且都垂直于光轴）
   │                                                    │
Y 振镜 → X 振镜                                        Galilei 扩束望远镜 / 动态调焦 (III)
   │                                                    │   ΔX_out = M·Δx，口径同比放大 M 倍
物镜 / 聚焦装置                                         │   一片镜组轴向毫米级移动 → 焦点 Z
   │                                                    │
工件                                                scanblock (IV)：Y 振镜 → X 振镜
                                                        │
                                                    物镜 / 聚焦工作单元 (V) → 工件
```

### 共同目的（两条路线其实在解同一个问题）

两者都用五个光学自由度同时控制两件事：

1. **光束在物镜入瞳上的位置** → 决定焦点处的**入射方向**（AOI / 倾斜）；
2. **光束进入物镜前的方向** → 决定**焦点在工件上的 X/Y 位置**。

于是焦点位置与入射方向可以近似独立地设定 —— 这就是"五轴"的意义，也是进动钻孔能控制孔壁锥度的原因。
差别只在**用什么物理机构去产生那个平行位移**：SCANLAB 用反射式多次折返，ARGES 用透射式平板的折射。

### 两条路线的公开证据等级不同（页面按三级色标如实区分）

| 级别 | SCANLAB 模式 | Novanta 模式 |
|---|---|---|
| 绿 · 公开确认 | 焦距 75 mm / 有效焦距 25 mm、AOI ±7.5°、Z ±1 mm、进动 ≤650 Hz | 五轴（X/Y/Z + 两个光束倾角）、物镜焦距 **60 mm**、进动 300–650 Hz、VIS/NIR 波段 |
| 紫 · 专利原理 | EP3932609B1 权利要求 1/2/4/5 的功能结构 | DE102004053298B4：两块平行平板、正交转轴、sin/相移 sin 驱动、望远镜 ΔX=M·Δx、scanblock |
| 橙 · 教学等效 | 可动镜分体镜面与台阶、Z 模块结构、镜间距与口径、物镜内部镜组 | 平板尺寸/厚度/折射率/间距、Galilei 焦距与倍率、物镜内部结构与有效焦距、补偿算法 |

**专利原理 ≠ 实机装配图**：专利给的是功能与权利边界，不是尺寸、位置、转轴或空间排布。

## 1. 它能让你在 5～10 分钟里看懂什么

两条路线都能看到：

- 扫描头的"五轴"为什么不是五根机床直线轴，而是**五个高速光学伺服轴**；
- 镜片 / 平板只动很小角度，为什么能显著改变焦点位置或入射角；
- 光束偏心进入物镜后，为什么**焦点基本不动、入射方向却变了**；
- Z 轴如何通过改变**物镜前光束的会聚状态**移动焦点；
- 为什么五个执行轴**必须联合标定**，而不是一轴对应一个坐标。

SCANLAB 模式特有：

- 振镜电机 / 转轴 / 反射镜 / 数字编码器如何组成**闭环光学轴**；
- 镜片只转很小角度，反射光方向为什么变化约**两倍**角度；
- α、β 模块如何靠**四次反射**让输出光束保持平行但产生横向位移；
- 为什么 Z 模块的折返镜**没有自己的执行轴、却每帧都在转**（随动解算）。

Novanta / ARGES 模式特有：

- 一块**平行平板**倾斜时，为什么出射光仍然与入射光**严格平行**、只是横移；
- 两块板为什么只用**绕两根正交横向轴倾斜**就能合成任意方向的平行位移；
- 为什么"一板正弦 + 另一板相移正弦"给出的是**近似**圆而不是精确圆（位移对倾角非线性）；
- Galilei 望远镜为什么同时把**平行位移**与**光束口径**放大同一个 M 倍；
- 为什么"精确圆补偿"是一个**数值逆解**问题（解每块板的机械角），以及它与简单 sin/cos 的差别有多大。

## 4. 光学模型是怎么算的

所有光线都由 **起点 + 单位方向**表示。两条路线的共同点是：镜片姿态、光束折线、焦点位置、
读数面板上的每个数字，都来自**同一次追迹**，没有任何"手工摆放"的假光路。

### 4.1 SCANLAB 模式

每一次反射都由镜面法向算出：

```
d_reflected = d − 2·(d·n)·n
```

```
用户命令 (X, Y, Z, α, β)
  → educationalInverseModel() 或 naiveInverse()   ← 解出五个执行轴
  → traceTrain()（逐面反射追迹）
  → 入瞳状态 (h, u, v, 半径, 会聚度)
  → 焦点状态 (X, Y, Z, AOI, 光锥角)
```

#### 4.1.1 与公开数值自洽的物镜等效模型

公开值：物镜焦距 75 mm、**有效焦距 25 mm**、典型入射光束直径 2 mm、典型全会聚角 0.08 rad。模型后段传播距离取 75 mm，不代表确认实机工作距离。

本模型把物镜等效为"内部扩束 M=3 + 焦距 75 mm 聚焦镜"，于是四个公开值互相自洽：

| 关系 | 结果 |
|---|---|
| 2 mm 光束扩到 6 mm，聚焦到 75 mm | 半角 atan(3/75) = 0.04 rad → 全角 **0.08 rad** ✓ |
| 有效焦距 = 1 / 0.04 | **25 mm** ✓ |
| 焦点位置 | `X = 25 mm × u`（u = 入瞳处主光线坡度） |
| 入射角 | `AOI = atan(−h / 25 mm)`（h = 入瞳处主光线相对光轴的高度） |

515 min. focus 版本（入射光束 2.5 mm）自动得到 0.1 rad 全角，与规格表一致 —— 见 `src/tests/objective.test.ts`。

#### 4.1.2 怎么确认"光线与镜面的关系是对的"

画面上每个反射点都会画出三样东西（"显示 → 镜面法线"开关控制）：

- 黄色小球：光线与镜面的**实际命中点**（直接取自追迹结果）；
- **青色短线**：该点的**镜面法线（垂线）**，长度 16 mm；
- 白色横线：镜面内的切向，与法线垂直，用来确认镜面朝向。

入射光与反射光关于这条青色法线对称，这就是模型的全部依据 `d′ = d − 2(d·n)n`。
点击任意一块镜片，右侧信息卡会给出**当前光线的实测入射角与偏转角**（2×入射角），
它和画面上的法线是同一份数据，不存在"画一套、算一套"。

想快速核对 45° 折叠关系，可用正视视角（相机沿 +Y 方向、与振镜等高）：
45° 镜在正视图中呈现为标准斜线，竖直入射与水平出射严格关于镜面对称。
`node tools/closeups.mjs` 会生成 `screenshots/cu-front-*.png` 这组检查图。

#### 4.1.3 渲染上踩过的坑

- **"机器中间有一块黑墙把整机截断"**：那是被写错的地面。
  本项目 **Z 轴是竖直方向**（工件表面 z = 0、扫描头在上方），而 `PlaneGeometry` 默认就躺在
  XY 平面、法向 +Z —— 这已经是一块合格的水平地面，**不需要旋转**。
  早期照搬"Y 向上"的习惯写了 `plane.rotation.x = Math.PI / 2`，
  结果把 900 mm × 900 mm 的地面转成了一面**竖直墙**，正好穿过机器中轴（y = 0）：
  默认视角在墙的一侧，于是"只能看一半机器"；视角跨过 y = 0，墙跑到身后，整机就出现了。
  修法就是删掉那行旋转（见 `create-scene.ts → addGround`）。
- **雾也会"吃掉"半个机器**：原来有 `Fog(900, 2400)`，相机离得远时远端部件会淡入背景色。
  现在直接不使用雾。
- three.js 里 **metalness 接近 1 的材质如果没有环境贴图会渲染成纯黑**：
  早期镜片 metalness 0.95 又没有 `scene.environment`，所以"看不清每个镜片"。
  现在用 `PMREMGenerator + RoomEnvironment` 生成环境贴图，金属才真正呈现为镜面。
- 光束画得太粗太亮会盖住镜片：现在中心光线半径增益降到 0.9、包络降到 1.6，
  并把振镜电机从 6.5 mm 半径缩到 2.8 mm，让镜面成为视觉主体。
- 每块镜片都单独克隆材质并加一圈高亮轮廓（`EdgesGeometry`），
  这样"高亮某个轴、其余降透明度"不会互相干扰，镜片边界也始终清晰。
- 物镜原来是两段饱和紫蓝色的空心大圆筒，看起来像"悬在光路上的胶囊"；
  现在改为中性玻璃灰蓝的三段镜筒 + 金属加强环 + 内部镜组 + 出光口。
- **Z 模块两块镜片粘在一起（穿模）**：折转镜与折返镜的落差原来只有 16 mm，
  而两片 20 mm 的 45° 镜片各自的 Z 向半投影约 14 mm，屏幕上看就是两块镜片互相穿插。
  现在落差取 34 mm，并加了 `geometry-overlap.test.ts` 用 OBB 判定做回归保护。
- **随动折返镜"凭空自己动"**：它没有执行轴却每帧在转，因为法向是解出来的。
  现在为它补了一台电机，读数用本帧解出的法向求带符号角（见 4.4）。
- 排查这类"有东西挡住画面"的问题时，可以用 `node tools/diagnose-occlusion.mjs`：
  它会拍默认视角、逐个隐藏分组（`window.__PRECSYS__.groups`）各拍一张，便于按排除法定位。

#### 4.1.4 α/β 平行移束模块

依据专利 **EP3932609B1**（Claim 1/3/4/5、[0015][0030][0032]）：

- 三面平面镜：一面可转（26，振镜驱动）+ 两面固定（28、30），三镜法向共面；
- 光束反射 **四次**，第 1 次与第 4 次都落在可转镜上；
- 数学结论：出射方向 `φ_out = φ_in + 2(θ₂₈ − θ₃₀)`，**与可转镜转角 θ₂₆ 无关**。
  所以可动镜转动只让出射光束**横向平移**，方向不变 —— 即专利所说的
  "parallel offsetting the laser beam relative to an optical axis"。

本模型的实现细节（`src/optics/parallel-shift-module.ts` 与 `src/tests/parallel-shift.test.ts`）：

- 两块固定镜法向相同 → 输出方向与输入**严格平行**（测试断言偏差 < 1e-9 度，全行程成立）；
- 可动镜机械角 ±3.5° 对应约 ±7 mm 移束行程，灵敏度约 2 mm/度；
- 专利未规定单镜 26 的具体结构。模型自定**同一振镜支架上的两块平行镜面 + 法向台阶**，
  只能演示功能，不能证明已复原专利单镜，更不能推断实机必有背面入射或开孔。
- F1→F2 段现在按有限光束、旋转局部轴、斜入射足迹、板厚及安全余量校验。
  典型光束通过不代表宽光束在全行程通过，失败会在侧栏显式告警。

#### 4.1.5 Z 动态调焦等效模块

公开资料没有给出 precSYS Z 轴的完整生产结构。[0043] 举例轴向移动光学元件，
权利要求 6 未将此机制规定为唯一实现。本模型采用反射式教学功能等效，不据此推断实机 Z 轴类型：

- 可动折转镜受执行器驱动真实偏转，光线按反射定律逐面计算；
- 折返镜法向每帧由"入射方向 → 目标方向 −Z"解出，输出严格沿 −Z；
- 变焦反射镜曲率随执行器信号在**凸—平—凹**之间变化，直接实现"改变物镜前光束会聚度"，
  输出会聚度 = 2·cos(入射角)/R；
- ±1 mm 焦点范围只需约 ±0.8° 执行器角。

**关于折返镜的"随动"**：折返镜没有自己的执行轴，它的法向是每帧被解出来的，
因此页面给它单独画了一台电机，读数用**本帧解出的法向相对名义法向的带符号角**
（不能用执行器角驱动，否则显示出来的角度是错的）。这也是页面上会出现
**5 个驱动外形**的原因：4 台振镜电机（5 个模型执行轴中的 X/Y/α/β）+ 1 个 Z 三透镜直线调焦台；
不是 precSYS 第六轴或第六台电机的公开证据。

**关于角度指示弧（×12）**：Z 轴走完 ±1 mm 全程只需要约 ±0.8°，
转子上的键位在这个量级下肉眼等同静止。因此每台电机额外画一段
**放大 12 倍显示**的指示弧，方向与转向一致，标签上标注 `×12`。
它只是读数指示，**不参与任何光学计算**，镜片姿态与光线仍按真实角度计算。

页面固定显示：

> 此处为动态调焦功能等效模型，展示"改变物镜前光束会聚状态 → 改变焦点 Z"的关系，
> 不代表 precSYS 内部真实镜组排布。

#### 4.1.6 为什么必须联合标定

模型里存在两类由所选教学几何计算得到的耦合，不代表实机的结构或标定值：

1. **Y 振镜不在等效入瞳参考位置**（两片振镜相距 16 mm，是本模型选取），
   所以 Y 扫描移动焦点的同时会把一部分 Y 向偏心带进入瞳 → 不需要的入射角分量；
2. **Z 执行器改变光束在折返镜上的落点**，使下行光束整体横移 → 同样变成入瞳偏心。

`naiveInverse()`（一轴对应一坐标）忽略这些耦合，残差可达几度；
`educationalInverseModel()` 用有限差分求出 5×5 耦合矩阵并做牛顿迭代，
把 (X, Y, Z, α, β) 同时解到位（残差 < 0.01）。页面上的"联合补偿"开关就是这两者的切换。

**注意**：`educationalInverseModel()` 是等效逆映射，**不是** SCANLAB 控制器算法，
也不代表实机标定矩阵。

### 4.2 Novanta / ARGES 模式（依据 DE102004053298B4）

#### 4.2.1 专利原文给出的光路顺序

> "…a row of the following components arranged in the light path of the laser:
> an intensity-regulating beam attenuation unit **(I)** in conjunction with a parallel
> displacement adjusting **wobble unit (II)**, a beam cross-section of the laser magnifying
> **beam expander telescope (III)**, a focus of the laser beam leading **scan block (IV)**
> and a laser beam on the sample focusing **work unit (V)**…"

本模型据此装配：

```
激光 → 光束强度衰减单元 (I) → wobble unit (II)：两块平行平板
     → Galilei 扩束望远镜 / 动态调焦 (III)
     → scanblock (IV)：Y 振镜 → X 振镜
     → 物镜 / 聚焦工作单元 (V) → 工件
```

#### 4.2.2 向量折射追迹（`src/optics/refraction.ts`）

平行平板必须做**真实的三维折射追迹**，不能用一个二维公式"假装"折射：

```
d_refracted = η·d + (η·cos θᵢ − cos θₜ)·n̂ ,   η = n₁/n₂
sin²θₜ = η²(1 − cos²θᵢ) > 1  ⇒  全内反射，返回 null（不静默降级）
```

一次追迹给出：入射面交点、玻璃内方向、出射面交点、出射光线、横向位移向量、
以及入射角 / 玻璃内折射角 / 出射面入射角等诊断量。
**画面上的红色折线、数值读数、AOI 与 offset 全部来自这一份追迹结果。**

三条可验证性质（`src/tests/refraction.test.ts`）：

| 性质 | 断言 |
|---|---|
| 空气 → 平行板 → 空气，出射方向与入射方向平行 | 方向偏差 **< 1e-9 度**（全角度范围） |
| 位移随倾角单调 | 0°→20° 逐点递增 |
| 倾角符号翻转 → 位移反号 | 位移向量逐分量对称 |
| 解析式 `Δ = t·sin(i−r)/cos r` 与追迹一致 | 误差 < 1e-9 mm |

#### 4.2.3 两块板的机械运动方式

专利明文：*"both the first plane-parallel window and the second plane-parallel window
rotatably mounted, wherein the respective axes of rotation and the propagation direction of
the laser beam are orthogonal to each other"* —— 两块板的转轴**互相正交**、且**都与传播方向正交**。

本模型（**Educational equivalent orientation**，即教学空间排布）：

- 平板 A 绕 **X 轴**倾斜 → 横向位移沿 **Y**；
- 平板 B 绕 **Y 轴**倾斜 → 横向位移沿 **X**。

板的姿态严格来自追迹结果（入射面法向与参考点），因此**不存在"绕光轴连续自转来伪造进动"**：
两板只是各自绕一根固定的横向轴摆动，而合成的位移向量在绕光轴旋转。

#### 4.2.4 进动：为什么简单 sin/cos 不是精确圆

专利给出的驱动是"一板正弦、另一板相移正弦"，并明确说：

> "A closer inspection shows that when tilting the plates dependent on a sine function or a
> cosine function, no exact circular path of the generated beam offset is achieved. The
> deviation is about one percent at the used tilt angles of about 18°."

原因在模型里可以直接看出来：单板位移是 `d = t·sin(i−r)/cos r`，对倾角**非线性**。
本模型的位移沿 lateral 轴正比于 `sin θ`，因此两轴正交驱动时 `Δx/Δy = sin θ_B / sin θ_A`，
只有在小角度才近似等于 `cos φ / sin φ`。

本模型提供两种教学驱动策略：

| 策略 | 做法 | 结果 |
|---|---|---|
| **Patent Simple Sin/Cos** | `θ_A = A·sin φ`、`θ_B = A·sin(φ+Δ)`（专利描述） | 近似圆；相位差 0° 退化为直线，其它值给出椭圆 / Lissajous |
| **Compensated Circular Offset** | 给定 `Δx = R cos φ`、`Δy = R sin φ`，对每块板做**数值逆解**（二分法）机械角 | 非圆度降到数值精度级 |

页面同时给出**本模型实测**的非圆度、半径极差、闭合误差与两板瞬时角。
**注意**：本模型的非圆度数值取决于本模型自选的板厚、折射率与倾角约定，
**不声称复现专利正文里那个约 1% 的数字**，也不声称厂商控制器存在同样的偏差。

页面明确标注：

> **Educational compensation model — controller implementation is not publicly disclosed.**

#### 4.2.5 Galilei 扩束望远镜 / 动态调焦（`src/optics/galilean-telescope.ts`）

专利明文：

- 望远镜是**折射式**镜组；两镜组焦点重合（afocal）；放大倍率 `M = f₂/f₁`；
- 出射光束尺寸 `D_BET = M·d`；平行位移被放大 **`ΔX_BET = M·Δx`**；
- **Galilei（凹＋凸）** 因结构更短、镜组之间没有实焦点而被优先采用；
- 凹透镜与/或准直镜组可沿光轴作**毫米级**移动 → 改变数值孔径、光束不再准直，
  *"Damit geht eine Änderung der Z-Position des Brennflecks einher."*

本模型用**同一套近轴 ABCD 矩阵**同时给出位移放大与口径放大（二者必须是同一个 M），
并由矩阵的 C 项给出输出会聚度（afocal 时 C = 0，即仍准直）。
关键校核写在 `src/tests/galilean-telescope.test.ts`：

- afocal 条件解出 `d = f₂ − f₁`（f₁ < 0），此时出射**严格平行**（方向偏差 < 1e-9 度）；
- 实测位移比 = 实测口径比 = `M`；
- 零位 C = 0、V = 0；执行器行程单调改变焦点 Z，且逆解可反算。

**教学参数**（专利未给出任何数值）：f₁ = −15 mm、f₂ = +60 mm、口径 25 mm、
Z 执行器行程 ±1.5 mm、物镜内部等效扩束比 1。

#### 4.2.6 物镜与 AOI

公开确认：PE III 物镜焦距 **60 mm**（官方数据表）。未公开：有效焦距、内部镜组、
入射净孔径与工作距离。

本模型为建立自洽的教学关系，取**有效焦距 = 公开焦距 = 60 mm**，并明确标为教学选取：

```
焦点位置  X = Feff · u            （u = 入瞳处主光线坡度）
入射角    AOI = atan(−h / Feff)   （h = 相对光轴的入瞳偏心）
焦点深度  Z = f(入瞳会聚度)        （与 SCANLAB 模式共用同一套物镜等效关系）
AOI 幅值  sqrt(α² + β²)
AOI 方位  atan2(β, α)             ← 由两个倾角分量派生的极坐标表达
```

**不要把"平板 A = AOI 轴、平板 B = Plane 轴"写进模型** ——
AOI 与 Plane 是两个倾角分量派生出的极坐标量，不是一板对一轴。

#### 4.2.7 两条路线为什么可以共用同一套求解器

`educational-inverse-model.ts` 通过 `InverseTrainAdapter` 访问"追迹一次 / 取结果 / 裁剪行程"三件事，
完全不知道内部是四次反射的反射式移束模块，还是两块透射平板。
于是：

- **两条路线的耦合矩阵本来就不一样**（因为耦合来源不同），页面各自如实展示；
- 而求解代码只有一份。

Novanta 拓扑下的一阶关系（本模型的解析对照，页面读数仍以真实追迹为准）：

```
焦点 X ≈ 2θ_X·f + (1 − L/f)·h        L = 最后一片振镜到入瞳参考面的距离
```

本模型把下游 X 振镜的命中点同时用作"最后一片振镜"与等效入瞳参考，即 `L = 0`，
于是**平板位移只改变入瞳偏心（→ AOI）、不改变焦点 X/Y**，
"平板改变光束位置、XY 振镜改变光束方向"这条解耦关系在模型里是成立的、可被测试钉住的。

页面用三种色标区分每一条信息：

| 色标 | 含义 | 例子 |

| 橙 · 教学等效 | 为讲清原理而建立的等效模型 | 可动镜的分体镜面与法向台阶、转轴取向、XZ/YZ 光路平面、镜间距与口径、X/Y 振镜排布与通道映射、Z 模块光焦度与随动件、物镜内部镜组与后段传播距离 |

**关键区分：专利原理 ≠ 实机装配图。** 专利给出的是功能与权利边界，
不是尺寸、位置、转轴或空间排布。因此本轮把下面这些**从"公开确认/专利原理"下调为"教学等效"**：

- X 振镜与 Y 振镜的位置、转轴、折向 +X 的排布，以及"X 振镜 = 入瞳平面"的说法
  （改为"以 X 镜命中点作**等效入瞳参考**"，倾斜镜面不等于水平入瞳面）；
- 监测分光元件的取样位置与传感器排布（分光监测功能本身有公开依据）；
- 平行移束模块内部结构：单镜 26 的分体台阶替代、转轴、尺寸、XZ/YZ 排布；
- 物镜内部镜组与"后段传播距离 = 工作距离 75 mm"的表述
  （公开的是**焦距** 75 mm 与有效焦距 25 mm，工作距离未公开）；
- Z 随动折返镜（**没有独立自由度，不是实机第六轴**，电机外形仅为示意）。

**AOI 的口径**：`AOI = atan(−h/Feff)` 中的 `h` 是相对**机器光轴**的入瞳偏心，
AOI 是相对传播参考轴 **−Z** 的有符号角分量。工件水平时参考轴与表面法线平行；
工件倾斜需另算光线与表面法线夹角。专利 Fig.3 的 α/β 表示的是出光倾角与工件入射角，
**不是**本页的 X/Y 分量，本页换算公式专利未给出。

**不做的事**：不把教学模型标成"precSYS 内部真实 CAD"；不虚构镜片型号、材料、镀膜、尺寸与公差；
不根据外壳照片猜测内部镜片位置；不把网页计算结果当作真实加工参数或安全边界；
不宣称网页做了衍射、像差、热漂移或材料去除的精确仿真；
不用"中心光线能解出"冒充"有限光束能安全通过"（见下）。

**几何校验**（侧栏"事实边界 / 几何校验"卡片）：

- 只校验 α/β 的 F1→F2 段对两可动镜片的**包络避让**，计入 1/e² 光束包络、
  斜入射足迹、2.6 mm 板厚投影与 0.25 mm 安全余量；
- 零位缝宽 57.12 mm 沿镜面 u 轴测量，**与 11 mm 法向台阶不是同一个量**；
- 典型半径 1–1.25 mm 在 ±3.5° 全行程余量为正；半径 3 mm 在 +3.5° 时
  保守余量 −2.04 mm，卡片转为**红色告警**；
- 这是局部避让校验，**不是整机无碰撞认证**，也不保证高斯光束尾部零截光。

**视觉放大**（页面右上角常驻显示）：

- 光路轴向长度按教学需要拉开，**非等比例**（实机主体参考包络约 303.5 mm × 271 mm）；
- 焦点 Z 位移放大 ×6（公开范围仅 ±1 mm，等比绘制肉眼不可见）；
- 光束会聚度放大 ×60；
- 电机转角指示弧放大 ×12（真实机械角常只有零点几度，不放大等同静止）；
- **Novanta 望远镜镜组的轴向行程绘制放大 ×8**（真实全程 ±1.5 mm，等比绘制不到 10 px，
  不放大等同"镜片没动"；透镜在光学模型里的位置仍按真实行程计算）；
- 进动动画是慢动作：650 Hz 的真实一圈约 1.5 ms，浏览器帧率不是真实控制周期。

### 9.1 SCANLAB 模式

# 本次更新：新增 Novanta / ARGES 技术路线

## 2026 增补 —— 第二套五轴实现与两条路线对照

在**不改动、不替换**现有 SCANLAB precSYS 实现的前提下，新增了一整套独立的
**Novanta / ARGES — Patent-Derived Precession Architecture**，并在页面顶部提供技术路线切换。

### 新增了什么

- **向量折射追迹**（`src/optics/refraction.ts`）：三维 Snell 定律、光线-界面求交、玻璃内传播、
  出射面折射、全内反射判据与数值容差。平行平板做的是真实 3D 折射追迹，
  **不是**用二维公式假装折射；画面折线、读数与 AOI/offset 全部来自这一份追迹。
- **两块透射式平行玻璃板**（`plane-parallel-plate.ts` + `dual-plate-precession.ts`）：
  两板转轴正交且都垂直于光轴（专利明文），板 A 绕 X 倾斜 → 位移沿 Y，板 B 绕 Y 倾斜 → 位移沿 X；
  板**不绕光轴自转**，只有合成的位移向量绕光轴旋转。
- **进动与补偿策略**：Patent Simple Sin/Cos（专利描述）与 Compensated Circular Offset（教学数值逆解），
  页面同时给出实测非圆度、半径极差与闭合误差。
- **Galilei 扩束望远镜 / 动态调焦**（`galilean-telescope.ts`）：
  位移放大与口径放大共用同一个 M（`ΔX = M·Δx`），由系统矩阵的 C 项给出输出会聚度；
  afocal 时 C = 0（出射严格平行），失配时移动焦点 Z。
- **scanblock 与物镜**（`novanta-optical-train.ts` + `novanta-objective.ts`）：
  45° 折转对（法向由 d_out − d_in 的角平分线关系定死）、物镜等效与 AOI/Plane 极坐标。
- **三维场景**：两块透明玻璃板（真实厚度、两个平行表面、可见玻璃内光路）、望远镜、
  两片振镜、物镜、工件；8 个快捷视角（含 **Dual-Plate Top View**）；
  侧栏新增**位移轨迹面板**（当前 offset 向量 + 整圈实测轨迹 + 理想圆）。
- **事实边界体系**：沿用仓库原有的三级色标（公开确认 / 专利原理 / 教学等效），
  新增两条技术路线对照表与 Novanta 专属的"已知的未知"清单。
- **求解器复用**：`educational-inverse-model.ts` 通过适配器同时支持两条路线 ——
  两条路线的**耦合矩阵本来就不一样**，页面各自如实展示，而求解代码只有一份。

### 本次实现过程中发现并修掉的问题

- **近轴算子的符号约定**：`traceTelescope` 与系统矩阵必须共用同一套传播/薄透镜算子，
  否则会出现"afocal 时出射光不平行"。现已统一为 `y' = y + d·m`、`m' = m − y/f`，
  并用"会聚透镜把平行光聚到下游 f 处"这条纯几何判据在测试里钉住。
- **系统矩阵的合成次序**：写成 `((L₁·P)·L₂)` 会把两片透镜的次序颠倒，
  导致 C ≠ 0、放大倍率变成 1/M。现已改为 `M = L₂·(P·L₁)` 并加硬断言。
- **45° 折转对的几何**：镜面法向必须取 `d_out − d_in` 的角平分线方向，
  且两片镜心必须各自落在自己的平面上；凭感觉写会让整条光路跑偏。
- **平行平板的定位基准点（画面错位，最隐蔽的一个）**：
  入射面是"过 `pivot`、以 `n(θ) = R(r,θ)·n₀` 为法向"的平面。因为转轴 r ⊥ n₀，
  所以 `pivot` **恒在该平面上**，定位时不需要也不应该跟着转。
  早期实现把 `pivot` 绕转轴旋转了一个倾角 —— 光学计算完全正确（平面没变），
  但 `pivot` 位于光轴上、离板面有约 400 mm 的力臂，**10° 倾角会把三维里的玻璃板
  沿光轴横向甩出 70 mm 以上**，表现为"两块板漂到光路旁边、而红色光线看起来还是直的"。
  现在 `plateAnchorAt()` 返回恒定 `pivot`，板心再沿 −n 后退半个板厚；
  倾角 20° 时的残余位移只有 1.8 mm，正是"半板厚沿法向投影"应有的量。
  `parallel-plate.test.ts` 增加两条回归：基准点在 ±20° 内恒等于 `pivot`、
  且到该倾角入射面的距离恒为 0。
- **行程饱和没有被报出来**：补偿模式下目标半径超出机械行程时，`tiltForPlateShift`
  会把机械角夹到端点，此时追迹成功、口径也可能通过，但**位移比目标小**。
  现在 `PrecessionTrajectory` 增加 `tiltSaturated` 字段，并把"转不到"与"装不下"
  一起计入 `ok = false`（`apertureClear` 仍单独报告口径问题）。
- **Novanta 的 Z 轴演示"镜片不动"（两处叠加原因）**：
  1. **命令幅值贴着行程端点**：轴演示的 Z 幅值沿用了 SCANLAB 的 ±1 mm，
     而 Novanta 可达焦点 Z 只有约 ±0.27 mm，命令被 `clampCommand()` 压到上限后
     曲线削顶、求解器长期顶在行程端点。现在按路线分别取幅值（Novanta ±0.2 mm），
     命令上限也留 10% 余量，并对这条路线多给两次牛顿迭代。
  2. **真实行程太小、等比画看不见**：Z 执行器全程只有 ±1.5 mm（焦点 Z ±0.26 mm），
     绘制出来不到 10 px。现在按 `VISUAL_GAIN.novantaLensTravel = 8` 放大**绘制位移**
     并在页面上标注；透镜在光学模型里的位置仍取真实行程，光线与读数不受影响。
- **执行器没有绑在所驱动的光学件上**：振镜电机的挂点原来直接用镜心，
  结果被塞进镜片自身内部而看不见；平行平板的电机挂在光轴上的 `pivot`，
  壳体压住玻璃板与标签。现在振镜电机外移到镜面背后、平板电机沿转轴移到板缘之外，
  Z 执行器移到凹透镜上游。
- **场景标签偏大**：`.scene-label` 11px → 10px、`.motor-label` 11px → 10px，
  并收紧内边距、给长标签限宽，特写下不再糊成一片。
- **CSS2D 标签泄漏**：切换技术路线时，已摘除分组里的标签 DOM 节点不会被
  `CSS2DRenderer` 自动清理，表现为 SCANLAB 的"α 电机 / L1 移动"永久叠在 Novanta 模型上。
  现在 `detachGroup()` 会显式移除这些节点，并有专门的浏览器断言防回归。
- **部件卡渲染被覆盖**：程序化切换模式时，"先渲染结构依据、再被一次快照渲染覆盖"
  会把卡片刷成空白；现在由单一入口 `renderModeCard()` 统一渲染。
- **进动策略面板建不起来**：`ensurePrecessionPanel()` 在启动时（此时还是 SCANLAB 路线）
  会先因 `hidden` 提前返回，导致切到 Novanta 后只看到一个空卡片。
  现在先建内容、再判可见性，并在切换路线时重新调用。
- **`**强调**` 标记**：配置文案里的强调标记原先会原样显示成星号，
  现在统一经 `renderInlineMarkup()` 渲染。
